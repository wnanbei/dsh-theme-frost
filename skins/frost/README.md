# Frost

Frost is a neutral DeepSeek Harness skin for sustained reading and work. Light mode pairs a paper-white canvas with graphite actions; dark mode uses cool graphite surfaces and inverted near-white actions.

## Features

- Complete light and dark semantic token palettes.
- CSS only: no hooks, remote resources, or background media.
- Skin Center semantic selectors, with no generated class-name fragments.
- Neutral surfaces, soft elevation, visible focus, and polished native details.

## Install

Copy this directory to `~/.dsh/skins/frost/`, reload DSH, and select Frost in **Settings → Skins**. The directory name must match the manifest `id` and must be a real directory, not a link.
