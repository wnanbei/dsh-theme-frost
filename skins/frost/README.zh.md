# 霜白 · Frost

霜白是一套为 DeepSeek Harness 长时间阅读与工作设计的中性主题。浅色是纸白画布与石墨主按钮，深色是冷石墨层级与反白主操作。

## 特点

- 亮暗双主题，完整重映射官方语义 token。
- 纯 CSS，无 hooks、无远程资源、无背景媒体。
- 使用 Skin Center 的语义属性，不依赖 hash 类名。
- 中性层次、柔和阴影、清晰焦点与原生控件细节。

## 安装

将本目录复制到 `~/.dsh/skins/frost/`，重新加载 DSH 后在 **设置 → 皮肤中心** 选择 Frost。目录名必须与 `skin.json` 的 `id` 一致，且必须是真实目录。
